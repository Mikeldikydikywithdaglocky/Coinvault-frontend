# CoinVault Account Assets

The account workspace uses the existing CoinVault favicon as its brand mark.

- Cryptocurrency marks: https://github.com/spothq/cryptocurrency-icons (license in `crypto/LICENSE.md`).
- Inter font: https://github.com/rsms/inter (license in `fonts/LICENSE.txt`).
- MTN mark: favicon published by https://www.mtn.com/, retrieved via Google's favicon service. MTN remains the trademark owner's brand.
- Telecel mark: official PNG from https://telecel.com.gh/icons/icon-512x512.png. Stored locally so withdrawals do not depend on a favicon lookup service.
- AirtelTigo/AT mark: official PNG from https://www.at.com.gh/assets/img/at-logos/at-logo-sm.png. AT is the provider's current branding; the existing payout provider ID and name remain unchanged.
- Ghana bank marks are stored locally for withdrawal history: GCB (https://www.gcbbank.com.gh/templates/gcb2017/images/logo.png), Ecobank (https://www.ecobank.com/img/eco/apple-touch-icon.png), Absa (https://www.absa.com.gh/content/dam/ghana/absa/logos/absa-logo-bg-gh.png), CAL Bank (https://calbank.net/wp-content/uploads/2025/02/logo-300x300.png), and Fidelity (https://fidelitybank.com.gh/favicon.ico, a PNG response). Each remains its owner's trademark.
- Feather Icons 4.29.2, QRCode.js 1.0.0, and the existing Tailwind 3.4.17 utility loader are vendored in `js/vendor`, with their licenses beside the scripts.

No sample account identities, wallet addresses, balances, API keys, or payment credentials are included in these assets.
